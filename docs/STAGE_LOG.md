# 阶段记录

历史文档曾把“代码存在、自动化通过、旧部署存在”统一写成 Completed。0.2.0 起不再沿用这种口径；逐阶段文件、测试、真实/mock 分类、剩余问题和用户操作统一记录在 [ACCEPTANCE.md](ACCEPTANCE.md)。

## 2026-07-16 至 2026-07-17：原型阶段

- 建立 EPUB/TXT 解析、Web、Firebase/Rules、配对、任务、播放器、删除与私密 Firestore 设计。
- 完成多轮单元、Emulator、Playwright 和合成公共资产网络测试。
- 使用本机已有开发环境做过 Qwen MPS 短基准。
- 这些证据没有证明全新 Mac 安装、源码独立性、完整私密云链路或真实 iPhone。

## 2026-07-18：0.2.0 接手审计与修复

- 阶段 0：发现安装器、Qwen 正式依赖、硬编码、错误日志、试听 Origin、Rules 查询与文档证据等级问题。
- 阶段 1：建立 Agent/Qwen 两套锁、托管 Python、正式模型目录和真实模型自检。
- 阶段 2：建立双击安装/更新/卸载、LaunchAgent 安全重载、版本健康检查、回滚与源码独立性验证。
- 阶段 3：修复 Qwen stderr/stdout IPC、私密书规划、长文本分片、任务状态围栏；真实声音 WAV/M4A 成功。
- 阶段 4：增加网页系统状态、自动修复和 Blob 试听加载。
- 阶段 5：修复 collection-group 403、最小 Worker 书籍读取权限并真实部署 Rules。
- 阶段 6：真实私密任务已完成 Qwen、FFmpeg、Firestore 分片/哈希/READY；真实 iPhone 已完成所有者正文/音频回读、用户声音确认、后台与锁屏播放、位置恢复。删除重生成仍是验收门。
- 阶段 7：CI/Pages 已发布；移动登录、EPUB 占位标题、私密正文空闲刷新和章节首个可播放段修复已进入 `main`。

## 2026-07-18：iPhone 真机验收与后续修复

- iPhone Safari 打开 Pages、Google 登录、头像和账号书架同步通过。
- owner-only 私密正文和私密 M4A 回读通过，用户确认是自己的声音。
- 当前段落高亮、锁屏媒体信息、锁屏控制、后台播放、返回 Safari 和位置恢复通过。
- 真机截图发现 EPUB 显示 `Section0001`，解析器与旧书加载修复为正文标题。
- 真机截图发现章节首段无音频时错误停在 00:00，播放器修复为跳到该章首个可播放段。
- Mac 空闲时可刷新变更后的私密正文；旧私密副本在新指针成功后清理。
- 正在生成时不强行更新，新增通用空闲更新脚本，待检查点锁释放后只更新 Agent runtime。
- 来电/耳机中断、网络切换、主屏幕 PWA、真实物理重启和删除重生成仍未完成真机验收。
