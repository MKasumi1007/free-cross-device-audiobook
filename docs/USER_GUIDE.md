# 普通用户指南

## 安装前

- 目前正式安装器只支持 Apple Silicon Mac（M1/M2/M3/M4 及后续 arm64）。
- 至少保留 6 GiB 可用磁盘；模型约 2.3 GiB，安全更新需要额外临时空间。
- 首次安装需要网络。无需预装 Node、Python、Homebrew、FFmpeg 或 Qwen。
- 安装和本机生成不要求银行卡，也不会启用 Firebase Blaze 或付费 GPU。

## 第一次安装

1. 在 GitHub Releases 下载 `听见书页安装器-0.2.0.zip` 并解压。
2. 双击 `听见书页安装器.app`。开源安装器没有付费 Apple Developer 签名；若 macOS 拦截，请在 Finder 右键安装器并选择“打开”。
3. 等待安装器完成 Python、两套运行环境、音频工具、模型下载和真实短音频自检。不要在中途合上 Mac。
4. 成功后点击“打开听见书页”。以后也可双击 `~/Applications/听见书页/听见书页.app`。
5. 打开网页右上角“系统状态”，确认 Agent、Qwen 依赖、模型、MPS、FFmpeg 和磁盘没有失败项。

## 登录和连接 Mac

1. 点击“登录同步”，完成 Google 登录。
2. 点击“连接这台 Mac”。网页会优先自动连接 localhost；必要时使用 Agent 生成的六位短码。
3. 页面显示有效 Mac 绑定且最近十分钟有心跳，才表示云任务可以被这台 Mac 领取。
4. 断开连接会撤销 Worker 权限，不会删除书、声音或进度。

## 添加书籍

1. 只能在 Mac 网页点击“添加书籍”；手机不会出现导入按钮。
2. 通过 macOS 原生选择器选择 EPUB 或 TXT。网页不能读取任意本机路径。
3. 不确定传播权时保持默认私密 `LOCAL_ONLY`。不要为了方便勾选公开权利。
4. 原始文件不会上传；解析结果保存在本机。私密正文只在首次私密生成需要手机阅读时进入账号隔离 Firestore。

## 设置声音

1. 打开“我的声音”，选择 10–30 秒、环境安静、只有一个人的录音。
2. 填写录音中实际说出的完整文字。文字为空或明显不匹配会被拒绝。
3. 系统会归一化为 24 kHz 单声道，在本机生成试听。
4. 播放试听，确认满意后点击“确认使用”。声音和参考文字留在 Mac，不上传。

## 生成和收听

1. 登录后点击书架或阅读页的“选择待生成章节”。
2. 可以跨多本书勾选任意章节，再加入“待生成列表”。
3. 在列表中使用上下箭头调整先后，也可以暂停、继续或移除尚未生成的章节。
4. 正在生成的小段不会被强行打断；暂停、移除和排序从下一小段开始生效。
5. Mac 必须在线、有交流电和足够内存；否则任务会等待，不会转用付费云端。
6. Worker 一次只处理一个任务，并严格按待生成列表顺序工作。Qwen 按段写 WAV 检查点，再用 FFmpeg 合成 M4A。
7. 远程 READY 音频达到约 5 小时时暂停继续生成；旧音频满 5 天删除后，自动接着处理队列。
8. 私密正文、时间线和音频拆成 Firestore 小文档，全部写完并通过哈希后才标记 READY。
9. 第一块 READY 后即可播放。Mac 关机后，已经上传的私密音频仍可由同一账号读取，待生成列表也不会丢失。

## 手机使用

手机登录同一 Google 账号后可以打开书架、正文和已经 READY 的音频，也可以选择章节、调整待生成顺序、暂停、继续和移除任务。手机只管理队列，不运行 Qwen；实际语音仍由 Mac 免费生成。遇到问题请记录 iOS 版本、Safari/PWA、操作步骤和系统状态截图。

## 更新

双击 `~/Applications/听见书页/更新听见书页.app`。更新器从 `main` 下载源代码，建立 `.next` 环境，自检后原子切换；新 Agent 注册或健康检查失败时恢复 `.previous`。书架、声音、模型和生成检查点不参与运行时替换。

## 卸载

双击 `~/Applications/听见书页/卸载听见书页.app` 并确认。它会删除：

- LaunchAgent；
- Agent/Qwen 运行环境；
- 托管 Python、uv、下载的音频工具；
- 安装/更新/卸载入口。

它明确保留：

- `books`；
- `voices`；
- `generation`；
- `models`。

卸载不会删除 Firestore 云端数据。当前没有“一键彻底删除所有私人数据”按钮，避免误删；如确需完全清除，应先备份并走单独审计流程。
